# Board Pinout

One page to check before you wire anything: what each board already connects to its pins, which pins are safe to use, and which pins every experiment uses. The board user manuals have the full details: [UM1472](https://www.st.com/resource/en/user_manual/um1472-discovery-kit-with-stm32f407vg-mcu-stmicroelectronics.pdf) (F407 Discovery) and [UM1724](https://www.st.com/resource/en/user_manual/um1724-stm32-nucleo64-boards-mb1136-stmicroelectronics.pdf) (Nucleo-64).

On the Discovery, pin 1 of P1 and P2 is the square pad at the ST-LINK end, and every pin name is also printed on the board next to its pin.

::: danger Never use PA13 / PA14
They are the SWD debug pins on both boards. Assign them to anything else and the debugger can no longer connect. See [Setup Guide → Know your board](/setup/#_2-know-your-board).
:::

## F407 Discovery

### Wired on the board

These pins already connect to something on the Discovery board. Use them for that part, or check the note before reusing them.

| Part | Pins | Note |
| --- | --- | --- |
| Green / orange / red / blue LEDs (LD4, LD3, LD5, LD6) | PD12 / PD13 / PD14 / PD15 | Active high. PD12–PD15 are TIM4 channels 1–4. |
| User button B1 (blue) | PA0 | Active high, with an on-board pull-down. Also WKUP and TIM2/TIM5_CH1. |
| SWD debug | PA13 (SWDIO), PA14 (SWCLK), PB3 (SWO) | Never reuse PA13/PA14. PB3 only matters if you use SWV trace. |
| 8 MHz crystal (HSE) | PH0, PH1 | Not available as GPIO. |
| Accelerometer (SPI1) | PA5 SCK, PA6 MISO, PA7 MOSI, PE3 CS, PE0 / PE1 INT | |
| Audio DAC CS43L22 | PB6 SCL, PB9 SDA (I2C1); PA4 WS, PC7 MCK, PC10 SCK, PC12 SD (I2S3); PD4 reset | The LCD shares I2C1 with this chip. They have different addresses, so both work on the same bus. |
| Microphone MP45DT02 | PB10 CLK, PC3 DOUT | |
| USB OTG FS | PA9 VBUS, PA10 ID, PA11 DM, PA12 DP, PC0 power enable, PD5 overcurrent | PA9 also lights the green VBUS LED. |
| BOOT1 | PB2 | Has a resistor to GND; avoid. |

::: tip PA4 and PA6 are shared, and that is fine
Experiment 3 reads the potentiometer on PA4 and the LDR on PA6, which are also wired to the audio DAC and the accelerometer. Neither chip drives those lines while it sits idle, so the ADC readings are normal. If a reading on one of them looks wrong, move that sensor to a free ADC pin such as PA1 or PC1 and change the channel to match.
:::

### Free for your circuits

Nothing on the board connects to these, so they are the safest picks for LEDs, buttons, keypads and sensors:

| Port | Free pins |
| --- | --- |
| A | PA1, PA2, PA3, PA8, PA15 |
| B | PB0, PB1, PB4, PB5, PB7, PB8, PB11–PB15 |
| C | PC1, PC2, PC4, PC5, PC6, PC8, PC9, PC11, PC13 |
| D | PD0–PD3, PD6–PD11 |
| E | PE2, PE4–PE15 |

Free pins with ADC channels: PA1 (IN1), PA2 (IN2), PA3 (IN3), PB0 (IN8), PB1 (IN9), PC1 (IN11), PC2 (IN12), PC4 (IN14), PC5 (IN15).

## F411 Nucleo-64

### Wired on the board

| Part | Pins | Note |
| --- | --- | --- |
| User LED LD2 (green) | PA5 (D13) | Active high. |
| User button B1 (blue) | PC13 | Active **low**: reads 0 when pressed. |
| ST-LINK virtual COM port (USART2) | PA2 TX, PA3 RX | Used by the UART labs. By default they go to the ST-LINK only, not to the D1/D0 header pins (solder bridges SB62/63 open). |
| SWD debug | PA13 (SWDIO), PA14 (SWCLK), PB3 (SWO) | Never reuse PA13/PA14. |
| 32.768 kHz crystal (LSE) | PC14, PC15 | Avoid. |
| 8 MHz clock from ST-LINK (MCO) | PH0 | Not available as GPIO. |

### Arduino header

The Arduino-style header is the quickest way to find a pin on the Nucleo. Every other pin is on the two long Morpho headers (CN7, CN10).

| Header | Pin | Header | Pin |
| --- | --- | --- | --- |
| A0 | PA0 | D8 | PA9 |
| A1 | PA1 | D9 | PC7 |
| A2 | PA4 | D10 | PB6 |
| A3 | PB0 | D11 | PA7 |
| A4 | PC1 | D12 | PA6 |
| A5 | PC0 | D13 | PA5 (LD2) |
| D0 | PA3 (VCP RX) | D14 | PB9 |
| D1 | PA2 (VCP TX) | D15 | PB8 |
| D2 | PA10 | | |
| D3 | PB3 (SWO) | | |
| D4 | PB5 | | |
| D5 | PB4 | | |
| D6 | PB10 | | |
| D7 | PA8 | | |

::: warning D14 / D15 are not I2C here
On many Arduino shields D14/D15 are SDA/SCL. On this board they are PB9/PB8, and Experiments 4 and 5 put TIM4_CH4 on PB9. Keep the LCD on **PB6 / PB7**, as in [Experiment 4](/experiments/exp4-timers).
:::
